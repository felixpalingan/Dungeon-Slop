# Dungeon-Slop ⚔️💀

A chaotic 1-6 player cooperative top-down dungeon crawler designed for friend slop fun. Delve as deep into procedural dungeon floors as possible!

## Features
- **100% Procedural 2D Vector Shapes**: Drawn with HTML5 Canvas math (zero external sprite sheets or images needed).
- **WebRTC P2P Multiplayer (PeerJS)**: Host and join lobbies instantly via 6-character room codes (`SLOP-XXXX`) with zero backend server setup.
- **Combat & Movement**: `WASD` movement, 360° mouse aiming, snappy sword slashing arcs, and **`Left Shift`** dodge rolls with after-images.
- **Slop Comedy & Sound FX**: Synthesized Web Audio effects (whooshes, hits, slaps) paired with floating comic popups (`DODGE!`, `SWOOSH!`, `BONK!`).
- **Interactive Lobby & Gear System**: Character name/color customizer, training dummy, slap physics, and 6-slot equipment systems.
